Atualização dos dados

Para manter o site online atualizado, substitua o arquivo dados.json na hospedagem. Você também pode importar a base estruturada pelo botão “Importar planilha” para revisar os dados no navegador.

  1. Atualize a planilha estruturada.
  2. Clique em Importar planilha.
  3. Confira o dashboard.
  4. Baixe o novo dados.json pelo botão abaixo.
  5. Substitua o arquivo antigo na hospedagem.
